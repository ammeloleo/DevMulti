BLOG ACADÊMICO — protótipo funcional

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra o index.html no navegador.
   - Opcional: use a extensão Live Server do VS Code para uma experiência melhor.

Funcionalidades incluídas:
- Navegação entre Início, Meus trabalhos, Calendário, Buddies, Notificações e Perfil.
- Criação de publicações com título, categoria e descrição.
- Curtidas e ações das publicações.
- Calendário com provas, entregas e eventos.
- Cadastro de novos eventos.
- Lista de trabalhos com progresso.
- Busca de colegas.
- Chat funcional de demonstração.
- Notificações e marcação como lidas.
- Layout responsivo para celular.

Observação:
Este é um protótipo front-end. Os dados ficam somente no navegador enquanto a página está aberta; para persistência real seria necessário um back-end/banco de dados.
