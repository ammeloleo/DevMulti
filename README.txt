# 🎓 BLOG ACADÊMICO

> **Protótipo funcional de uma plataforma acadêmica voltada à organização dos estudos, interação entre estudantes e acompanhamento de atividades universitárias.**

---

## 📌 Sobre o projeto

O **Blog Acadêmico** é um protótipo de uma plataforma digital desenvolvida para centralizar diferentes atividades do cotidiano acadêmico em um único ambiente.

A proposta é oferecer aos estudantes ferramentas para **organizar trabalhos e eventos, compartilhar publicações, acompanhar atividades, encontrar colegas e manter uma comunicação integrada**.

O projeto foi desenvolvido com foco na experiência do usuário, apresentando uma interface moderna, intuitiva e responsiva.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma solução que facilite a **organização e a interação no ambiente acadêmico**, reunindo recursos que normalmente ficam distribuídos entre diferentes plataformas.

Entre os objetivos específicos estão:

- Facilitar a organização de trabalhos e atividades;
- Permitir o acompanhamento de prazos e eventos;
- Incentivar a interação entre estudantes;
- Centralizar notificações e informações acadêmicas;
- Disponibilizar um ambiente para compartilhamento de publicações;
- Proporcionar uma experiência simples e acessível em diferentes dispositivos.

---

## ✨ Funcionalidades

### 🏠 Navegação

A plataforma possui diferentes áreas para organizar suas funcionalidades:

- **Início**
- **Meus trabalhos**
- **Calendário**
- **Buddies**
- **Notificações**
- **Perfil**

### 📝 Publicações

É possível criar publicações informando:

- Título;
- Categoria;
- Descrição.

As publicações também possuem ações de interação, como **curtidas**.

### 📅 Calendário acadêmico

O calendário permite visualizar diferentes compromissos acadêmicos, como:

- 📚 Provas;
- 📝 Entregas;
- 📌 Eventos.

Também é possível realizar o **cadastro de novos eventos**.

### 📊 Meus trabalhos

A seção de trabalhos permite visualizar as atividades acadêmicas e acompanhar o **progresso de cada trabalho**.

### 👥 Buddies

A plataforma conta com uma área para **buscar colegas**, facilitando a conexão e interação entre estudantes.

### 💬 Chat

Foi implementado um **chat funcional de demonstração**, simulando a comunicação entre usuários da plataforma.

### 🔔 Notificações

O sistema apresenta notificações relacionadas às atividades da plataforma e permite **marcá-las como lidas**.

### 📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência adequada em:

- 💻 Computadores;
- 📱 Celulares;
- 📲 Tablets.
